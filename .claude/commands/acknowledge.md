# acknowledge

Record that the person who raised a case has been told it was received.

Run `node scripts/cases.mjs acknowledge <ref> [--date=<YYYY-MM-DD>] [--detail="<how>"] --actor="<you>"`. Add `--json` when you need every field. Resolve the person or case by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Confirm in one line.
