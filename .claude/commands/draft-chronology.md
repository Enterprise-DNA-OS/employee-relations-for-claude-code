# draft-chronology

Write the case file: a chronology of every step, interview, piece of evidence, finding and decision, with deadlines and open problems. Written to drafts/.

Run `node scripts/cases.mjs draft-chronology <ref>`. Add `--json` when you need every field. Resolve the person or case by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Show the file path and any gap in the chronology.
