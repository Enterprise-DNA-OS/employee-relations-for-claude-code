# weekly-review

Write the Monday review to drafts/ from attention, the next 14 days of deadlines, challenge windows, compliance, workload and warnings expiring.

Run `node scripts/cases.mjs weekly-review`. Add `--json` when you need every field. Resolve the person or case by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Summarise in five lines: what is against the law, what is due this week, what is stuck, who is overloaded, what expires.
