# withdraw-warning

Withdraw a warning before it expires, with the reason.

Run `node scripts/cases.mjs withdraw-warning <ref> --reason="<why>" --actor="<you>"`. Add `--json` when you need every field. Resolve the person or case by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Confirm in one line.
