# compliance

Check every case against the rules in docs/compliance.md: law first, then guidance, fairness, house rules and notes, each with its source and the first example.

Run `node scripts/cases.mjs compliance`. Add `--json` when you need every field. Resolve the person or case by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Table: kind, rule, count, the first example. Never present a house rule or guidance as law.
