# draft-response

Draft the written response to a request: the decision, and for a refusal the ground and reasons the law asks for (s 69AAE and s 69AAF in New Zealand, s 65A or s 76A in Australia, the right to complain to the Privacy Commissioner). Written to drafts/, never sent.

Run `node scripts/cases.mjs draft-response <ref>`. Add `--json` when you need every field. Resolve the person or case by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
